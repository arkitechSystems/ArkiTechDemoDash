========================================
RENDER DEPLOYMENT GUIDE - CchdDash
========================================

PROJECT OVERVIEW:
This is a full-stack application with:
- Frontend: React (Create React App with TypeScript)
- Backend: Node.js + Express + TypeScript
- Database: SQLite (embedded)
- Authentication: JWT tokens with bcrypt password hashing

========================================
RECOMMENDED DEPLOYMENT: BLUEPRINT (EASIEST)
========================================

Your project now includes a render.yaml file that automates deployment of both services.

STEPS:
------
1. Log in to Render (https://render.com)

2. Click "New +" → "Blueprint"

3. Connect your GitHub repository:
   - Repository: https://github.com/Wmartin23/CchdDash.git
   - Branch: master

4. Render will automatically detect render.yaml and show you:
   - Backend API Service (cchddash-api)
   - Frontend Static Site (cchddash-frontend)

5. Review the configuration and click "Apply"

6. Wait for both services to build and deploy (5-10 minutes)

7. Your services will be live at:
   - Backend API: https://cchddash-api.onrender.com
   - Frontend: https://cchddash-frontend.onrender.com

IMPORTANT NOTES:
- Both services are FREE on the free tier
- Backend will auto-generate a secure JWT_SECRET
- Database is SQLite (ephemeral on free tier - resets on restart)
- Default login: Concho1 / password
- Auto-deploy when you push to GitHub

========================================
OPTION 2: MANUAL DEPLOYMENT (TWO SEPARATE SERVICES)
========================================

If you prefer to deploy the frontend and backend separately instead of using Blueprint:

BACKEND API (Web Service):
--------------------------
1. Go to Render Dashboard
2. Click "New +" → "Web Service"
3. Connect your GitHub repository
4. Configure:
   - Name: cchddash-api
   - Environment: Node
   - Root Directory: server (IMPORTANT!)
   - Build Command: npm install && npm run build
   - Start Command: npm start
   - Instance Type: Free

5. Add Environment Variables:
   - NODE_ENV=production
   - JWT_SECRET=<generate-a-random-secure-string>
   - PORT=3001

6. Click "Create Web Service"

FRONTEND (Static Site):
-----------------------
1. Go to Render Dashboard
2. Click "New +" → "Static Site"
3. Connect your GitHub repository
4. Configure:
   - Name: cchddash-frontend
   - Build Command: npm install && npm run build
   - Publish Directory: build
   - Auto-Deploy: Yes

5. Add Environment Variables:
   - REACT_APP_API_URL=https://cchddash-api.onrender.com

6. Click "Create Static Site"

IMPORTANT: The frontend MUST know the backend URL via REACT_APP_API_URL

========================================
MANAGING USERS
========================================

CREATE NEW USERS:
-----------------
Option 1: Use the API (when backend is running):
   curl -X POST https://cchddash-api.onrender.com/api/auth/register \
     -H "Content-Type: application/json" \
     -d '{"username":"newuser","password":"newpass","email":"user@example.com"}'

Option 2: Use the script locally:
   cd server
   npm run create-user <username> <password> [email]

   Example:
   npm run create-user john password123 john@example.com

DEFAULT CREDENTIALS:
- Username: Concho1
- Password: password

CHANGE DEFAULT PASSWORD:
Edit server/src/database.ts line 39 before first deployment

========================================
CUSTOM DOMAIN SETUP
========================================

1. In Render Dashboard, go to your service
2. Click "Settings" → "Custom Domain"
3. Add your domain (e.g., dashboard.arkitech.com)
4. Update DNS records at your domain registrar:
   - Type: CNAME
   - Name: dashboard (or @)
   - Value: [provided by Render]
5. Wait for DNS propagation (up to 24 hours)

========================================
TROUBLESHOOTING
========================================

BUILD FAILURES:
- Check Node version (Render uses Node 14+ by default)
- Verify all dependencies are in package.json
- Check build logs for specific errors
- Ensure PUBLIC_URL is set correctly if using subdirectories

ROUTING ISSUES (404 on refresh):
- For static sites, add _redirects file to public folder:
  /*    /index.html   200
- For web services, ensure catch-all route is configured

ENVIRONMENT VARIABLES NOT WORKING:
- Must prefix with REACT_APP_ for Create React App
- Rebuild after adding/changing environment variables
- Check "Environment" tab in Render dashboard

PERFORMANCE OPTIMIZATION:
- Enable caching headers
- Use CDN for static assets
- Compress images before deployment
- Consider using Render's paid tier for better performance
